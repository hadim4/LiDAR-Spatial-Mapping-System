# LiDAR Spatial Mapping System

**MSP432E401Y | Embedded C | Python | Open3D**

Designed and implemented a **360° spatial scanning system** using an MSP432E401Y (ARM Cortex-M4F) microcontroller and VL53L1X LiDAR sensor to collect distance measurements and generate 3D point-cloud representations of the surrounding environment.

## Key Features

- **360° Spatial Scanning:** Developed a scanning system with an angular resolution of 11.25°.
- **Embedded Firmware:** Implemented bare-metal C firmware to interface with the VL53L1X LiDAR sensor.
- **Sensor Communication:** Used I²C for real-time distance measurements and UART to transmit data to a host PC.
- **3D Point-Cloud Visualization:** Processed and visualized LiDAR measurements using Python and Open3D.
- **Mechanical Design:** Modeled and 3D-printed custom mounting components using AutoCAD Inventor.
